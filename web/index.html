阿里云

              

                登录阿里云控制台 → 云服务器 ECS → 网络与安全 → 安全组 → 找到实例绑定的安全组 →
                配置规则 → 入方向 → 手动添加。协议类型选择“自定义 UDP”或“自定义 TCP”，端口范围照抄上方清单，
                授权对象填 0.0.0.0/0。
              

            

            

              
腾讯云

              

                登录腾讯云控制台 → 云服务器 → 安全组 → 找到实例关联的安全组 → 入站规则 → 添加规则。
                协议端口照抄上方清单，来源填 0.0.0.0/0。
              

            

            

              
服务器系统防火墙

              

                云安全组放行后，如果服务器启用了 firewalld 或 ufw，还需要在系统防火墙中放行相同端口。
                CentOS 可用 firewall-cmd 追加端口，Ubuntu 可用 ufw allow。
